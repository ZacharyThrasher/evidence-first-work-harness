# Harness reference/template library

**Normal v2 users should not start here.** Open top-level `START_HERE.html` or install `claude-skill/efwh/` and run `/efwh <problem>`.

This directory is retained as the auditable static protocol/template library. The v2 Skill reads these resources and writes project-specific goal/config/state artifacts automatically under `.efwh/`. Manual initialization remains possible for teams that deliberately want it.
