# Wiki

This directory is the **high-signal synthesis layer**. It is not raw evidence.

Pages should be short enough to reload into context efficiently and should link claims to evidence IDs/source references.

Recommended page structure:

- current understanding;
- what is directly observed vs documented vs inferred;
- unresolved contradictions;
- implications for decisions;
- stale/freshness notes;
- relevant evidence IDs.

Use `PAGE_TEMPLATE.md`.
