# Adapter — Document / Technical Research

## Orientation additions

Discover internal knowledge bases, file repositories, ticket history, standards subscriptions, web access, and relevant SMEs.

## Evidence priority

Use internal system-of-record documents for organization-specific facts and primary external sources for general claims. Record dates/versions because procedures and technical docs age.

## Experiments

An “experiment” may be:

- a targeted contradiction search;
- checking an assertion against a primary document;
- calculating from source data;
- comparing revisions;
- asking an SME a specific discriminating question;
- testing a claim against a small prototype or environment observation.

## Evaluation

Check citation coverage, source quality, contradictions, date/freshness, and whether conclusions exceed what the sources actually establish.
