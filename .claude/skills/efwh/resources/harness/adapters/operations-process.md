# Adapter — Operations / Process Investigation

## Orientation additions

Map SOPs/runbooks, ticketing/workflow systems, owners, audit logs, SLAs, permissions, and staging/dry-run capabilities.

## Preferred experiments

Use simulation, dry run, historical replay, read-only log analysis, or a reversible staging action before touching a live process.

## Evaluation

Define observable process outcomes: time, error rate, handoff count, policy compliance, user burden, incident rate, or other operational metrics.

Externally visible actions and live-system changes are normally human-gated.
