# Candidate / Hypothesis Registry

The registry prevents path dependence and premature “impossible” conclusions.

Valid statuses:

- `UNEXPLORED`
- `RESEARCHING`
- `ACTIVE`
- `PROMISING`
- `BLOCKED`
- `RULED_OUT`
- `SELECTED`
- `SUPERSEDED`
- `NOT_APPLICABLE`

Each candidate should record:

- the exact proposition/approach;
- why it is materially distinct;
- evidence for and against;
- the next discriminating test;
- risk/cost;
- the **scope** of any rule-out.

Do not use `RULED_OUT` for “the first implementation attempt failed.” Rule out the proposition only when the evidence actually supports that scope.
