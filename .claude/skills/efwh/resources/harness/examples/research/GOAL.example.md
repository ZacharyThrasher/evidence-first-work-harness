# Example — Research

## Problem statement
Determine whether an undocumented platform capability can be invoked programmatically rather than through a manual GUI flow.

## Desired outcome
Identify the highest-confidence supported or private mechanism, or produce scoped evidence showing why each plausible path fails.

## Success criteria
- Primary platform/vendor evidence used where available.
- Working manual path traced before reimplementing lower-level protocols.
- Candidate registry includes public API, private user-mode API, shell/IPC, semantic UI automation, and driver-level routes if applicable.
- “Impossible” is not claimed while a credible untested user-mode path remains.
