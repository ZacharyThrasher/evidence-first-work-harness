# Example — Data Analysis

## Problem statement
A production yield metric dropped last week, but it is unclear whether the change reflects a real process shift, a product-mix effect, or a data-pipeline issue.

## Desired outcome
Produce a reproducible evidence-backed explanation of the primary contributors and quantify their impact without modifying production data.

## Success criteria
- Reconcile the analyzed population to the official weekly total.
- Evaluate at least product mix, site/tool/test-program changes, and pipeline freshness/definition changes.
- Every material result links to a reproducible query or stable result artifact.
- No PII or confidential row-level data leaves approved systems.
