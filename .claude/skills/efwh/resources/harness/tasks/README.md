# Tasks

Tasks are small enough to evaluate cleanly. A task is not just “do work”; it is a contract linking an uncertainty or deliverable to an observable outcome.

Before execution, fill `CURRENT.md` from `TASK_TEMPLATE.md`.

At task closeout:

1. record actual outcome;
2. link evidence artifacts;
3. run declared evals;
4. update candidates/wiki/decisions/state;
5. create a session handoff if a context/session boundary is near.
