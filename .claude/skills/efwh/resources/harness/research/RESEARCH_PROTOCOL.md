# Research Protocol

## Objective

Convert uncertain problem context into a scoped, provenance-backed knowledge base that is useful for action.

## Order of operations

1. Start from the environment/source registry.
2. Search authoritative internal sources where they are likely to contain organization-specific truth.
3. Use primary external sources (official docs, standards, original papers) for general technical facts.
4. Use secondary/community sources for discovery, edge cases, and experience—not as silent substitutes for primary support when stronger evidence exists.
5. For important conclusions, actively search for contradicting evidence or alternative explanations.

## Claim discipline

Use these labels:

- `OBSERVED`
- `DOCUMENTED`
- `INFERRED`
- `HYPOTHESIS`
- `DISPROVEN`
- `SUPERSEDED`

Every material wiki claim should point to evidence IDs or explicit source citations. State the scope of observations and disprovals.

## Research breadth

Default to a single agent. Parallel/subagent research is justified when branches are independent, breadth is high, and the value justifies the cost. Merge subagent results through the same evidence rules; subagent prose is not primary evidence.

## Stop researching when

- the current uncertainty is low enough to select a high-information experiment/task;
- additional source gathering is unlikely to change the next decision;
- the research budget is exhausted;
- a human gate is reached.

Research is not a substitute for testing when the environment can answer the question directly.
