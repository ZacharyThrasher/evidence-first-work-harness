# Support

For ordinary defects, confusing behavior, or feature requests, open a GitHub issue with:

- Claude Code/model version;
- EFWH version;
- the `/efwh` invocation (redacted as necessary);
- selected autonomy/rigor;
- expected behavior;
- actual behavior;
- the smallest non-sensitive `.efwh/` artifact excerpt that demonstrates the problem.

For security issues, use [SECURITY.md](./SECURITY.md) instead of a public issue.

For company-specific policy questions, contact your internal Claude Code/platform owner; public EFWH defaults cannot override local governance.
